# 📚 MySQL Database Practicals (DBMS)

## 📌 Overview

This repository contains all my practical work for the Database Management Systems (DBMS) subject using MySQL. It includes multiple assignments and projects covering database design, implementation, and query execution.

---

## 📂 Contents

### 1️⃣ Bookstore Management System

A mini-project that models a real-world bookstore database.

* Designed relational schema for books, customers, orders, and payments
* Implemented primary and foreign key relationships
* Focused on real-world database design and normalization

### 2️⃣ MySQL Practicals (Class Work)

This section includes all hands-on SQL queries and exercises performed during lab sessions.

* Basic SQL queries (SELECT, INSERT, UPDATE, DELETE)
* Joins, subqueries, and aggregate functions
* Constraints (PRIMARY KEY, FOREIGN KEY, UNIQUE, CHECK)
* Practice on data manipulation and retrieval
