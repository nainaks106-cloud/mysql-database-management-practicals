About This Repository
This repository contains the complete solution for a Database Management Systems (DBMS) practical exam. 
The exam consists of 10 scenario-based sets, and each student is assigned one set. All 10 sets have been 
solved and documented here for reference and study purposes.
Each set follows the same structure — a real-world database scenario, 5 related tables with
proper schema design, and 25 SQL queries ranging from basic SELECT statements to complex JOINs,
subqueries, aggregations, and date-based filters.
What's Covered
The 10 scenarios covered across this exam are:

Set 1 — Online Bookstore
Set 2 — Hospital Management System
Set 3 — University Management System
Set 4 — Airline Reservation System
Set 5 — Hotel Management System
Set 6 — Library Management System
Set 7 — Inventory Management System
Set 8 — Online Food Delivery System
Set 9 — Cinema Ticket Booking System
Set 10 — E-Learning Platform

Topics Practiced
This exam covers a wide range of core SQL concepts including SELECT with 
WHERE and ORDER BY, aggregate functions like COUNT, SUM, AVG, MIN and MAX, 
GROUP BY and HAVING clauses, INNER JOIN and LEFT JOIN across multiple tables, 
subqueries and nested SELECT statements, date functions like CURDATE, INTERVAL,
DATEDIFF and DATE_FORMAT, LIKE for pattern matching, and identifying NULL relationships 
for finding missing or unlinked records.

Tech Stack

Database: MySQL
Language: SQL
Tool: MySQL Workbench or MySQL CLI

How to Use
Clone the repository, open your MySQL client, 
create a database for your assigned set, 
and run the schema, data insertion,
and query files in order. 
Each set is self-contained and independent of the others.
