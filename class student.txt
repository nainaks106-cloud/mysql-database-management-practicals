class student:
  def __init__(self, name, age):
    self.name = name
    self.age = age

s1 = student("naina", 25)

print(s1.name)
print(s1.age)

class student:
Defines a class named student
A class is like a blueprint/template to create objects (real-world entities)
2️⃣ def __init__(self, name, age):
This is a constructor method
__init__ runs automatically when an object is created
It initializes (assigns values to) object properties

👉 Parameters:

self → refers to the current object
name, age → values passed during object creation
3️⃣ self.name = name
Creates an instance variable name
Assigns the passed value (name) to the object

👉 Example: "naina" gets stored in self.name

4️⃣ self.age = age
Creates another instance variable age
Stores the passed value (25) in the object
5️⃣ s1 = student("naina", 25)
Creates an object s1 of class student
Automatically calls __init__

👉 Internally:

__init__(s1, "naina", 25)
6️⃣ print(s1.name)
Accesses the name attribute of object s1
Output: naina
7️⃣ print(s1.age)
Accesses the age attribute of object s1
Output: 25
🧠 Simple Understanding (Real-life analogy)
class student → like a form/template
s1 → filled form (actual student)
name, age → details in the form
✅ Final Output:
naina
25
